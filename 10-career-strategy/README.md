# Career Strategy

The mentor track: honest assessment, sequencing, and the working documents you actually run.

| File | Use it when |
|------|-------------|
| [`AD-WALKTHROUGH.md`](./AD-WALKTHROUGH.md) | **Start here.** Eleven sessions, hand-held, from today's lab to an environment you can defend. Every step has what to expect and what to do if it fails |
| [`session-01-dns-and-privilege.md`](./session-01-dns-and-privilege.md) | Quick start if you only have 90 minutes today |
| [`CISO-MENTOR-REVIEW.md`](./CISO-MENTOR-REVIEW.md) | The strategic read: positioning, twelve months, three gates, what not to do |
| [`lab-roadmap.md`](./lab-roadmap.md) | Sixteen builds ordered by employer value per hour |
| [`weekly-log.md`](./weekly-log.md) | Fill this in every week. The "Failed" field is not optional |

## How these fit together

```
CISO-MENTOR-REVIEW  ── why this path, and what "good" looks like at each gate
        │
AD-WALKTHROUGH      ── what to do at the keyboard, in order, with expected output
        │
weekly-log          ── what actually happened, including what broke
```

The review is the plan. The walkthrough is the work. The log is the proof it happened.
