## Scope check — is this you?

| Question | If yes | If no |
|----------|--------|-------|
| Is it one user or everyone? | One user → continue | Everyone → **escalate**, likely server or network |
| Does it still happen after a log off and back on? | Continue | Token refresh was the cause — close |
| Did it work yesterday? | Note what changed | Check recent changes / mailbox / device |

## Prevention

> *The section that separates a KB article from a diary entry.*

- What causes this to recur?
- What would stop it happening again? *(a policy, a GPO exclusion, a monitoring check, a user-education line)*
- Is there a related ticket trend? *(3+ of these in a month means the cause is upstream — raise a problem record)*
